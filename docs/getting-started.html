Getting Started

  1. Download the Community Edition, extract the ZIP, and save a working copy.
  2. Open Getting Started in the workbook. Use Marathon Hub to find the next unfinished Main entry.
  3. Update H for status, I for completion date (YYYY-MM-DD), and Q for a rating from 1 to 10. Column J is the official planning estimate.
  4. Check Optional and Documentary reminders between Main release dates. Main access links point to providers, stores, or publishers when available. Region, purchase, or subscription restrictions may apply.
  5. Keep a backup. When a fresh edition is available, use the browser updater to carry status, ratings, and completion dates across.

Spreadsheet support

Macro-free XLSX tested in LibreOffice Calc. The maintainer opened and recalculated a browser-migrated workbook in desktop Microsoft Excel. Support across all Excel features and versions remains unverified.

The website works on mobile. Use a desktop or laptop for the workbook, as mobile spreadsheet apps may limit layout, navigation, and features.

What an upgrade transfers

The updater matches permanent IDs. Planning estimates and official references come from the new edition. Changes to Optional or Documentary source references stay in your old workbook. For a terminal-based alternative, see the offline migration guide.
